# ElectroMaster Mobile

Version Android basée sur le fichier HTML ElectroMaster fourni.

## Préparer le projet

1. Installer Node.js LTS et Android Studio.
2. Dans ce dossier : `npm install`
3. Initialiser Android si nécessaire : `npx cap add android`
4. Synchroniser : `npx cap sync android`
5. Ouvrir Android Studio : `npx cap open android`
6. Dans Android Studio, choisir un téléphone/émulateur puis Run.
7. Pour un APK : Build > Build APK(s).

Le contenu original est dans `www/index.html`.
